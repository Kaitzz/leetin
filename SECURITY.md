# Security Policy

## Reporting a Vulnerability

Please do not open a public GitHub issue for a suspected vulnerability in the live LeetIn service.

Use GitHub's private vulnerability-reporting feature for this repository. If it is not available, contact the maintainer privately through the contact information on their GitHub profile. Include:

- a concise description of the issue;
- the affected page or workflow;
- reproduction steps or a proof of concept;
- the potential impact; and
- a safe way to contact you.

Do not access other users' data, degrade the service, automate high-volume requests, or disclose the issue publicly before there has been a reasonable opportunity to investigate.

## Scope of This Repository

This repository is a non-deployable showcase and does not contain LeetIn's production implementation. Reports about missing production code, placeholder directories, or intentionally omitted configuration are not security issues.
